# Biber reduction within the unit, with measured reliability

*DYNAMICS-WEB series, 3 September 2026. Script `biber_within_unit.py`, built on `../reduction_biber/`
so features and PC1 are identical. 79,794 reddit comments in 399 subreddits with 50 or more scored
comments.*

The first run reported the reduction at three units: item r = −0.14, within subreddit mean r = −0.08,
between subreddit centroids r = −0.60. A between unit correlation can be inflated by composition (the
same comparison inflated a coupling slope six fold elsewhere in this programme), so the within unit figure
is the one that says whether a single comment's matter against manner tracks its own Biber D1.

| Quantity | Value |
|---|---|
| Pooled within subreddit r, both demeaned by room | **−0.081** |
| Permutation null (D1 shuffled within room, 200 draws) | mean −0.000, sd 0.003, none beyond the real value |
| Biber D1 single comment reliability, split half on alternate sentences, Spearman Brown (n = 35,363) | 0.53 |
| Matter against manner single read reliability, two reader agreement within domain on 45,502 cross site rows | 0.42 |
| **Within unit, corrected for both reliabilities** | **−0.17** |
| Item level, corrected the same way | −0.29 |
| Between subreddit centroids (Biber's own unit) | −0.60 |

## Reading

The reduction holds inside a room, one comment against one comment: the sign is right, the null is
twenty standard deviations away, and once the noise of a single read on both sides is taken out the
correlation is about −0.17, three per cent of shared variance. It is not the −0.60 of the genre level,
and the genre level figure should not be quoted as if it were a per text result. The honest sentence is
that Biber's dimension and the matter against manner axis agree on what a genre is far more than on what
a single comment is, which is what two instruments built to read genre profiles would be expected to do.
